Contribute
=========================

Useful places if you want to contribute to JRebirth projects.

<div class="jr-contrib-grid">
<div class="jr-contrib-card" id="bugs">
<p class="jr-contrib-title">Bugs Tracker</p>
<p>We use the GitHub issue tracker for feature requests and bugs.</p>
<p><a href="https://github.com/JRebirth/JRebirth/issues">Open issues on GitHub</a></p>
</div>
<div class="jr-contrib-card" id="ci">
<p class="jr-contrib-title">Continuous Integration</p>
<p>Builds and releases run on GitHub Actions.</p>
<p><a href="https://github.com/JRebirth/JRebirth/actions">View GitHub Actions</a></p>
</div>
<div class="jr-contrib-card" id="maven-repo">
<p class="jr-contrib-title">Maven Repository</p>
<p>Stable releases are published to <a href="https://central.sonatype.com/search?q=g:org.jrebirth.af">Maven Central</a>.</p>
<p>Development snapshots are available from <a href="https://github.com/JRebirth/JRebirth/packages">GitHub Packages</a>.</p>
</div>
<div class="jr-contrib-card" id="github">
<p class="jr-contrib-title">Source Code</p>
<p>Source code is hosted on GitHub under the JRebirth organization.</p>
<p><a href="https://github.com/JRebirth/JRebirth">github.com/JRebirth/JRebirth</a></p>
<p>Development happens on the <code>12.x-dev</code> branch.</p>
</div>
<div class="jr-contrib-card" id="maven">
<p class="jr-contrib-title">Maven Sites</p>
<p>Published Maven sites are available here:</p>
<p><a href="https://sites.jrebirth.org/">sites.jrebirth.org</a></p>
</div>
