JRebirth > Application Framework for JavaFX
Last Published: 2026-11-14  | Version: 12.0.0

Outstanding
Application
Framework

RIA Pattern providing perfect SoC
Simplify Multithreaded Development
Built according to KISS principle
Java 25 / JavaFX 26 / JPMS ready
Free & Open Source Library

No More Lags
No More Freezes

Manage all multithreading concerns efficiently without pain
UI tasks are automatically handled into UI thread
Long tasks are performed Thread Pools
Event Bus has its own thread

Avoid
Memory
Leaks

Release all Components when necessary
Manage all resources (Color, Font, Image, CSS, FXML)
All errors are caught and traced

Keep Your
Project
Well Organized

Main concerns are divided into Components
(Command Service Model)
Code can be shared among Components by using Behaviors
UI usage is highly flexible (w|wo FXML)

Modular
but not
over-engineered

Each Component can be overridden at runtime
Provide pluggable engine to enhance applications (branding)
Full JPMS modularization for Java 11+

JRebirth JavaFX Application Framework provides a really simple way to write sophisticated and powerful RIA and Desktop applications. By leveraging the best of previous RIA framework, we can deliver the ultimate one to work cleanly and efficiently with this awesome API. Check our overview page to see a diagram illustrating features and layers. Have also a look to JRebirth Tour presentation which was built with JRebirth presentation engine.
