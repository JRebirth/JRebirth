FontIcon Showcase

This showcase displays icons from the JRebirth iconfont-bridge modules.

Download and launch:

  • FontIcon Showcase (Portable ZIP — bundled runtime)
  • FontIcon Showcase (Windows EXE)
  1. Download the Portable ZIP.
  2. Unzip it on your machine.
  3. Run the launcher (FontIcon.bat / FontIcon.exe inside the image, or the top-level Windows EXE if you downloaded it).
  • Or download the Windows EXE, then double-click to start (requires a compatible Java runtime if the EXE is launch4j-wrapped without a bundled JRE).

Prefer the portable ZIP when possible: it includes a custom runtime built with jlink, so no separate JDK install is required.

Press F11 to toggle fullscreen.

You can browse the source code on: GitHub FontIcon Showcase.
