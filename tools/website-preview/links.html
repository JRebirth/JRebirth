Useful links

JRebirth provides versioned Maven sites. The default website (<www>) is mapped to the latest stable documentation. The WorkInProgress site (<wip>) tracks the development line. Previous generated sites remain available under <sites>.

All web sites

  • Website for latest stable version: www.jrebirth.org
  • Website for latest development version: wip.jrebirth.org
  • List of all generated Websites: sites.jrebirth.org

Javadoc

  • Latest stable version (all modules mixed): api.jrebirth.org
  • Latest development version (all modules mixed): wip-api.jrebirth.org
  • Latest stable version of core module only: api-core.jrebirth.org
  • Latest development version of core module only: wip-api-core.jrebirth.org

Software Factory

  • Latest Source: https://github.com/JRebirth/JRebirth/tree/12.x-dev
  • Continuous Integration: https://github.com/JRebirth/JRebirth/actions
  • Issue Tracker: https://github.com/JRebirth/JRebirth/issues
  • Maven Central: central.sonatype.com
  • GitHub Packages: github.com/JRebirth/JRebirth/packages
