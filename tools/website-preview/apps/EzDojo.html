EzDojo Manager

EzDojo Manager is a production club-management desktop client built on JRebirth AF 12 (JavaFX + JPMS). Use it to see the framework in a full product context — beyond demos and slides.

Downloads are hosted on the EzDojo product site (portable ZIP and Windows installer). The full source code is on GitHub.

Download and launch from the product site:

  • EzDojo Manager (Portable ZIP)
  • EzDojo Manager (Windows Installer)
  • Product website
