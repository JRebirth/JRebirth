Comparison Tool - Bundle utility

This application is used to find version differences between 2 folders containing some OSGI bundles. It could be extended to manage more file types using rexep or another custom algorithm.

Download (Windows):

  • Comparison Tool (Portable ZIP — bundled runtime)
  1. Download the Portable ZIP.
  2. Unzip the archive to a local folder.
  3. Open the unzipped folder and run bin/ComparisonTool.bat (double-click, or from a terminal).
  4. Do not use a standalone .exe next to a .jar — that wrapper is legacy and fails on modular JPMS apps. The ZIP is the supported launch path.

Prefer the portable ZIP: it includes a custom runtime built with jlink, so no separate JDK install is required.

Press F11 to toggle fullscreen.

You can browse the source code on: GitHub ComparisonTool repository.

Less boilerplate. Clean architecture. More time to build.
