EclipseCON France 2013 - JavaFX Workshop

This application has been shown during EclipseCON France 2013.

You can download workshop files (Eclipse Juno + m2eclipse + efxclipse + Maven standalone + Jdk7u21) : EclipseCON Workshop

Download (Windows):

  • EclipseCON Presentation (Portable ZIP — bundled runtime)
  1. Download the Portable ZIP.
  2. Unzip the archive to a local folder.
  3. Open the unzipped folder and run bin/EclipseCON.bat (double-click, or from a terminal).
  4. Do not use a standalone .exe next to a .jar — that wrapper is legacy and fails on modular JPMS apps. The ZIP is the supported launch path.

Prefer the portable ZIP: it includes a custom runtime built with jlink, so no separate JDK install is required.

Press F11 to toggle fullscreen.

  • Open Menu: Double Touch, Middle Mouse click
  • Next Slide: Mouse Left-click, Page Down, Swipe Left
  • Previous Slide: Mouse Right-click, Page Up, Swipe Right
  • Next Slide (skip step): Ctrl + Mouse Left-Click, Ctrl + Page Down, Double Swipe Left
  • Previous Slide (skip step): Ctrl + Mouse Right-click, Ctrl + Page Up, Double Swipe Right

You can browse the source code on: GitHub EclipseCON-France repository.

Less boilerplate. Clean architecture. More time to build.
