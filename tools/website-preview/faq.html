General

What is JRebirth ?

JRebirth is an Application Framework dedicated to the JavaFX UI toolkit (Java 25 / JavaFX 26 / JPMS).

Why should I use JRebirth ?

If you want to build a complex application using JavaFX toolkit you may consider using an Application Framework.

JRebirth has been built to facilitate developers' work by providing easy-to-use features that crunch complexity.

Main issues addressed

  • Concurrency within Multi-Threaded applications (single graphical thread, UI freezes & Deadlocks)
  • Memory Leaks
  • Thread Pool dedicated to long tasks
  • Asynchronous Messaging
  • Resources management (Fonts, Colors, Images, CSS, FXML)
  • Reusable Commands
  • Pragmatic Events Handling

All these topics are essential to build a reliable and maintainable application.

Less boilerplate. Clean architecture. More time to build.
