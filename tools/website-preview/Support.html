Support

How to get support or to give us some feedback

Bugs Tracker ------------------------------

We use the GitHub issue tracker for bugs and feature requests. You can submit difficulties or wishes there.

https://github.com/JRebirth/JRebirth/issues

Users Google Group ------------------------------

We use Google Groups to provide support to interested users. Don't hesitate to post if you want some help.

https://groups.google.com/group/jrebirth-users

Developers Google Group ------------------------------

We use Google Groups to exchange information about the project. Don't hesitate to post a new topic if you want to contribute.

https://groups.google.com/group/jrebirth-developers

Less boilerplate. Clean architecture. More time to build.
