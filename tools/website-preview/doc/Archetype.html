Create a JRebirth Application by using Maven Archetype

3-minute Tutorial

Command Line Tutorial

For Maven Gurus, here you have command lines to type to do the job.

Full Auto

![CLI OneLine](images/icons/view.gif) mvn archetype:generate -DinteractiveMode=false -DarchetypeCatalog=https://www.jrebirth.org/archetype/jrebirth-catalog.xml -DarchetypeGroupId=org.jrebirth.af -DarchetypeArtifactId=archetype -DarchetypeVersion=${project.version} -DgroupId=org.jrebirth.af -DartifactId=sample -Dversion=1.0.0-SNAPSHOT -Dpackage=org.jrebirth.af.sample

Interactive pre-filled

mvn archetype:generate -DarchetypeCatalog=https://www.jrebirth.org/archetype/jrebirth-catalog.xml -DgroupId=org.jrebirth.af -DartifactId=sample -Dversion=1.0.0-SNAPSHOT -Dpackage=org.jrebirth.af.sample

Full Interactive

![CLI Interactive](images/icons/view.gif) mvn archetype:generate -DarchetypeCatalog=https://www.jrebirth.org/archetype/jrebirth-catalog.xml

Less boilerplate. Clean architecture. More time to build.
